# 墨鱼排版 X 发布文案

## 正文

前前后后折腾了 47 天，终于把「墨鱼排版」做成了一个可以公开使用的开源项目。

它想解决一件很具体的事：把 Markdown 放进来，挑一个主题，稍微调整字体、间距和装饰，然后直接复制到微信公众号。

现在有 31 套主题，支持表格、代码高亮、Mermaid / Graphviz 图表转图片。所有处理都在浏览器本地完成，不用注册，文章也不会上传。

公众号排版不该只有一种标准答案。欢迎来体验、转发，顺手给 GitHub 点个 Star；如果你也喜欢字体、配色和版式设计，更欢迎一起创作新的主题。

体验：https://moyu.liaobuqi.ren

开源：https://github.com/JeasonKim/moyu-typeset

## 配图顺序

1. `01-workbench.png`：完整工作台与实际排版界面。
2. `04-theme-switch.mp4`：从清爽正文切换到潮流黑卡的完整动效。
3. `02-theme-gallery.png`：三种视觉方向的主题对比。
4. `03-content-features.png`：表格、代码与 Mermaid 图表效果。

如果 X 当前客户端不支持图片和视频混合上传，用 `04-theme-switch.gif` 替代 MP4。

## 图片替代文字

- 工作台：墨鱼排版桌面端工作台，左侧选择主题，中间预览文章，右侧调整文字和装饰样式。
- 主题对比：同一篇 Markdown 文章分别使用潮流黑卡、瑞士红线和新中式主题排版。
- 内容能力：公众号文章中的表格、任务列表、代码高亮，以及由 Mermaid 自动生成的流程图。
- 切换动效：墨鱼排版从清爽正文切换到潮流黑卡主题，经过墨鱼标志和聚光展开动画。
